Features

A few additions to make the desktop experience better.

▣

Dedicated desktop app

Access Nintendo Music in its own Electron application instead of a regular browser tab.

♫

Widevine DRM support

Uses a Castlabs Electron build with Widevine support for music playback.

◉

Discord Rich Presence

Optionally display your currently playing music on your Discord profile.

⌨

Keyboard controls

Use the spacebar to toggle playback when the application is focused.

About the project

Nintendo Music Desktop is an independent community fork of an existing Electron wrapper project. It adds modifications and optional features to the original desktop experience.

The project is open source and available on GitHub. Contributions and suggestions are welcome.

This is an unofficial community project. It is not affiliated with, endorsed by, or sponsored by Nintendo. Nintendo and Nintendo Music are trademarks of their respective owner.
